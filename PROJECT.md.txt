# SentinelOps

> **Monitor. Detect. Investigate. Respond.**

## Vision

SentinelOps is a production-quality Security Operations Center (SOC) platform designed to simulate real enterprise security operations.

This project is intended as a flagship cybersecurity portfolio demonstrating skills in:

- SOC Operations
- Blue Team
- Detection Engineering
- Incident Response
- Threat Hunting
- Secure Software Engineering
- FastAPI
- PostgreSQL
- Next.js
- Clean Architecture

This is NOT a CRUD application.

The application should resemble commercial platforms such as:

- Microsoft Sentinel
- Splunk Enterprise Security
- IBM QRadar
- Google Chronicle
- Elastic Security
- Wazuh

The project should be production-ready and suitable for deployment.

# Coding Rules

Use SOLID principles.

Use Repository Pattern.

Business logic belongs ONLY inside Services.

Routers should:

- Validate input
- Call service
- Return response

Never write business logic inside routers.

Use dependency injection.

Use type hints everywhere.

Use docstrings.

Follow PEP8.

3. Backend Foundation
4. Authentication
5. Dashboard
6. Detection Engine
7. Log Analysis
